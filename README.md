# EventM
## 🎉 Event Management for Corporate Employees
This project consists of two repositories:

- **Frontend**: [Link to Frontend Repository](https://github.com/aditi0057/Event_M)
- **Backend**: [Link to Backend Repository](https://github.com/aditi0057/EventM_Backend)

The frontend is built using Next.js and Tailwind CSS, while the backend is implemented with Node.js, Express, and MongoDB.

**EventM** is a smart event management platform designed to help corporate employees celebrate birthdays and anniversaries without the hassle of scheduling conflicts. With packed calendars and back-to-back meetings, it’s often difficult to find time for personal celebrations—but **EventM** ensures no special day goes unnoticed! 🥳

---

## 🚀 Features

### 🏠 Home Page

- A welcoming dashboard with an intuitive UI.
- Quick access to upcoming events and recent activities.

![image](https://github.com/user-attachments/assets/ac8e74f4-4591-4b09-97e4-0cd692845b01)


### 📅 Calendar

- Users’ birthdays and anniversaries are automatically recorded upon login.
- Personalized scheduling system to suggest optimal celebration times.


### 🎈 Event Calendar Page

- Displays events set by all users.
- Shows details like **date, time, and location** of upcoming celebrations.
- Ensures no overlap with critical meetings or work schedules.

### 🗳️ Poll Page

- Users and admins can create polls to decide on event dates, venues, and activities.
- Encourages team participation for seamless planning.
- Real-time voting and discussion for enhanced collaboration.

### 📸 Gallery Page (⭐ Cloudinary Integration ⭐)

- Users can **upload and share** event photos, creating a collaborative memory space.
- **Admins have the power to remove inappropriate images.**
- Secure and optimized storage using **Cloudinary**, ensuring high-quality images with fast delivery.

### 👤 Profile Pages

- **User Profile:** Manage personal event details and uploaded photos.
- **Admin Profile:** Oversee all events, polls, and gallery uploads with moderation controls.

## 🛠 Tech Stack

- **Frontend:** Next.js, Tailwind CSS
- **Backend:** Node.js, Express.js

## 🔧 Setup & Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/aditi0057/EventM.git
   cd EventM
   ```
2. Install dependencies:
   ```sh
   npm install
   ```
3. Setup environment variables in a `.env` file:
   ```
   MONGO_URI=your-mongodb-uri
   CLOUDINARY_CLOUD_NAME=your-cloudinary-cloud-name
   CLOUDINARY_API_KEY=your-cloudinary-api-key
   CLOUDINARY_API_SECRET=your-cloudinary-api-secret
   ```
4. Run the development server:
   ```sh
   npm run dev
   ```
